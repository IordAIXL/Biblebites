# Swaddling Was Not a Sacrificial-Lamb Code

**Passage:** Luke 2:7–16 (NET)  
**Evidence:** Strongly supported  
**Topic:** Christmas customs

**BIBLE BITE | Swaddling Was Not a Sacrificial-Lamb Code**  
**Passage:** Luke 2:7–16 (NET)  
**Evidence:** Strongly supported

**The bite:** Swaddling was ordinary newborn care: Luke’s verb means to wrap an infant, and ancient Jewish and Mediterranean evidence confirms the custom.[1] The unusual “sign” was a baby lying in a feeding trough.[2] No ancient source has been found for shepherds wrapping sacrificial lambs and placing them in mangers.[3]

**Why it matters:** Jesus as God’s Lamb is biblical theology, but the swaddled-lamb backstory is a modern illustration, not verified first-century history.
